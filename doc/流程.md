# 多對一遠端

> 多個使用者同時控制一個客戶端
> 被控端都有自己的房間（唯一）

- 開始遠端控制
  - 控制端，使用者點選連線，傳送billdDeskStartRemote訊息，開始遠端控制。
  - 被控端，監聽billdDeskStartRemote訊息，收到billdDeskStartRemote訊息後，判斷stream
    - 沒有stream，調原生介面獲取stream
    - 有stream，開始updateWebRtcRemoteDeskConfig，開始走webrtc流程（offer、answer等）
- 操作問題，所有進入遠端控制的使用者都可以進行操作（或者可以加個限制或者切換，一種是控制模式，另一種是觀看模式）。
- 結束遠端控制，使用者結束遠端控制。
  - 一對多，斷開一個不能影響其他連線
  - 被控端判斷有沒有使用者連線，只有當所有使用者都斷開連線的時候，才顯示已斷開遠端連線。

# 實際

- a使用者遠端客戶端
- 客戶端收到a使用者的遠端請求，獲取stream，然後和a使用者進行webrtc處理
- b使用者遠端客戶端
- 客戶端收到b使用者的遠端請求，獲取stream，然後和a使用者進行webrtc處理
